<Info>
  **전제 조건**: 계속하기 전에 Node.js(버전 19 이상)를 설치하세요.
</Info>

운영 체제에 Mintlify를 설치하고 실행하려면 다음 단계를 따르세요:

**1단계**: Mintlify 설치:

하하

<CodeGroup>
  ```bash npm
  npm i -g mintlify
  ```

  ```bash yarn
  yarn global add mintlify
  ```
</CodeGroup>

**2단계**: docs 디렉토리로 이동하여 (여기에 `mint.json` 파일이 위치함) 다음 명령어를 실행하세요:

```bash
mintlify dev
```

문서의 로컬 미리보기는 다음 주소에서 확인할 수 있습니다: `http://localhost:3000`.

### 사용자 지정 포트

기본적으로 Mintlify는 3000번 포트를 사용합니다. Mintlify가 실행되는 포트를 `--port` 플래그를 사용하여 사용자 지정할 수 있습니다. 예를 들어, Mintlify를 3333번 포트에서 실행하려면 다음 명령어를 사용하세요:

```bash
mintlify dev --port 3333
```

이미 사용 중인 포트에서 Mintlify를 실행하려고 하면, 다음으로 사용 가능한 포트를 사용합니다:

```md
Port 3000 is already in use. Trying 3001 instead.
```

## Mintlify 버전

각 CLI 릴리스는 특정 Mintlify 버전과 연관되어 있습니다. 로컬 웹사이트가 프로덕션 버전과 일치하지 않는 경우, CLI를 업데이트해 주세요:

<CodeGroup>
  ```bash npm
  npm i -g mintlify@latest
  ```

  ```bash yarn
  yarn global upgrade mintlify
  ```
</CodeGroup>

## 링크 유효성 검사

CLI는 문서에서 만든 참조 링크의 유효성을 검사하는 데 도움을 줄 수 있습니다. 깨진 링크를 식별하려면 다음 명령어를 사용하세요:

```bash
mintlify broken-links
```

## 문제 해결

<AccordionGroup>
  <Accordion title="Error: Could not load the &#x22;sharp&#x22; module using the darwin-arm64 runtime">
    이는 오래된 버전의 node로 인한 문제일 수 있습니다. 다음을 시도해 보세요:

    1. 현재 설치된 mintlify 버전을 제거합니다: `npm remove -g mintlify`
    2. Node v19 이상으로 업그레이드합니다.
    3. mintlify를 재설치합니다: `npm install -g mintlify`
  </Accordion>

  <Accordion title="Issue: Encountering an unknown error">
    Solution: Go to the root of your device and delete the \~/.mintlify folder. Afterwards, run `mintlify dev` 다시 실행합니다.
  </Accordion>
</AccordionGroup>
