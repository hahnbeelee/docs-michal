## 개발 환경 설정하기

문서를 로컬에서 업데이트하고 공개적으로 배포하는 방법을 알아보세요.

### 편집 및 미리보기

<AccordionGroup>
  <Accordion title="문서를 로컬에 복제하기" icon="github">
    온보딩 과정에서 우리는 Github에 문서 내용이 포함된 저장소를 생성했습니다. 이 저장소는 우리의 [dashboard](https://dashboard.mintlify.com)에서 찾을 수 있습니다. 저장소를 로컬에 복제하려면 다음 [instructions](https://docs.github.com/en/repositories/creating-and-managing-repositories/cloning-a-repository)을 터미널에서 따라하세요.
  </Accordion>

  <Accordion title="변경 사항 미리보기" icon="rectangle-terminal">
    미리보기를 통해 변경 사항이 의도한 대로 보이는지 확인할 수 있습니다. 우리는 이러한 변경 사항을 로컬에서 렌더링하기 위한 명령줄 인터페이스를 만들었습니다. 1. 다음 명령어로 [Mintlify CLI](https://www.npmjs.com/package/mintlify)를 설치하여 문서 변경 사항을 로컬에서 미리 볼 수 있습니다: `npm i -g mintlify`2. 문서의 루트 디렉토리에서 다음 명령어를 실행하세요 (`mint.json` 파일이 있는 곳): `mintlify dev`
  </Accordion>
</AccordionGroup>

### 변경 사항 배포하기

<AccordionGroup>
  <Accordion title="Github 앱 설치하기" icon="message-bot">
    우리의 Github 앱은 자동으로 변경 사항을 문서 사이트에 배포하므로, 직접 배포를 관리할 필요가 없습니다. 설치 링크는 [dashboard](https://dashboard.mintlify.com)에서 찾을 수 있습니다. 봇이 성공적으로 설치되면 저장소의 커밋 해시 옆에 체크 표시가 나타납니다.
  </Accordion>

  <Accordion title="변경 사항 푸시하기" icon="rocket">
    [변경 사항을 Git에 커밋하고 푸시하세요](https://docs.github.com/en/get-started/using-git/pushing-commits-to-a-remote-repository#about-git-push)문서 사이트에 변경 사항을 업데이트하려면 이 작업이 필요합니다. 푸시했는데 Github 앱이 변경 사항을 성공적으로 배포하지 않은 것 같다면, [dashboard](https://dashboard.mintlify.com)를 통해 수동으로 문서를 업데이트할 수도 있습니다.
  </Accordion>
</AccordionGroup>
